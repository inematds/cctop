🗺️Por que este módulo existe

Claude Code evolui rápido — skills, plugins, agents, hooks, slash commands — e novas ferramentas aparecem toda semana. Tentar acompanhar tweet a tweet é impossível. Awesome lists são a solução: alguém está curando, categorizando e mantendo para você.

As 6 listas abaixo têm focos diferentes. Use como primeiro lugar onde olhar quando pensar "será que já existe um...?". Marque os 2 ou 3 que combinam com seu stack e volte sempre que precisar.

1

⭐ hesreallyhim/awesome-claude-code

O índice oficioso do ecossistema Claude Code — mais abrangente e bem mantido da categoria.

↗ Abrir no GitHub

O que você encontra

  • ▸Skills por domínio (frontend, backend, DevOps, segurança)
  • ▸Hooks para validação, formatação, linting automático
  • ▸Slash commands customizados
  • ▸Agent orchestrators (frameworks para coordenar múltiplos agents)
  • ▸Applications & plugins construídos sobre Claude Code

Quando usar: como primeiro ponto de busca. Se você pensar "será que já tem um hook pra...?", comece aqui.

3

✨ travisvn/awesome-claude-skills

Lista focada 100% em skills — a mecânica mais nova e mais poderosa do Claude Code.

↗ Abrir no GitHub

Por que skills importam

Skills carregam sob demanda, ocupando ~5k tokens quando acionadas — nunca antes. Isso as torna extensões quase gratuitas em termos de contexto. Esta lista organiza skills por caso de uso: docs, revisão, design, automação, pesquisa.

Quando usar: quando /skill list estiver pobre. Procure aqui por skills que encaixem no seu workflow específico (ex: "revisar PRs React", "formatar docs Markdown").

4

🤖 VoltAgent/awesome-agent-skills

1000+ skills compatíveis com Claude Code, Codex, Gemini CLI, Cursor e outros.

↗ Abrir no GitHub

Times que mantêm skills ali

Anthropic Google Labs Vercel Stripe Cloudflare Netlify Trail of Bits Sentry Expo Hugging Face Figma + comunidade

Quando usar: se você alterna entre CLIs, ou prefere skills mantidas por empresas (não só comunidade). É o catálogo mais amplo que existe.

5

🎨 ComposioHQ/awesome-claude-skills

Skills + ferramentas focadas em integração com APIs externas (Slack, GitHub, Linear...).

↗ Abrir no GitHub

Foco

A Composio é uma empresa que mantém conectores para serviços SaaS. Esta lista reflete esse viés: você encontra skills para automatizar workflows entre Claude e ferramentas externas (criar issue no Linear a partir de um bug encontrado, postar resumo no Slack, abrir PR no GitHub).

Quando usar: automações cross-tool. Se seu caso de uso é "Claude + SaaS X", comece por aqui.

6

📊 quemsah/awesome-claude-plugins

Ranking de adoção de plugins via n8n workflows — o que a comunidade realmente usa.

↗ Abrir no GitHub

O diferencial

Outras listas mostram "o que existe". Esta mostra o que é adotado. Métricas automatizadas que rastreiam menções, downloads e instalações em repos GitHub. Atualização contínua via workflows n8n.

Quando usar: na hora de escolher entre dois plugins com funcionalidade parecida. Métrica de adoção ajuda a evitar plugin abandonado.

🎯Como incorporar na sua rotina

1️⃣

Bookmark os 2 principais

Sugestão: hesreallyhim (abrangência) + VoltAgent (skills corporativas). Cobrem 95% dos casos.

2️⃣

Antes de codar algo novo

Pense "isso é útil pra outros?" Se sim, alguém provavelmente já fez. Pesquise antes, crie depois.

3️⃣

Cheque manutenção

Data do último commit, issues abertas, número de stars. Plugin órfão quebra em silêncio — use quemsah como filtro de adoção.
