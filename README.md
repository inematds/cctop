# 🧠 Mestre em Contexto e Tokens

Curso prático para dominar o uso de contexto e tokens no Claude Code. Opere com disciplina: menos custo, mais qualidade, zero sessão estourada.

## Sobre

A cada mensagem, o Claude relê todo o contexto. Sessões longas ficam caras **e** piores em qualidade — o modelo se confunde, contradiz, esquece. Este curso ensina a rotina que corta essa curva pela metade.

**Regra de ouro:** contexto não é memória — é carga.

## Estrutura

6 trilhas • 18 módulos • ~108 tópicos • ~12h

| Trilha | Foco |
|--------|------|
| **T1 — Fundamentos** 🔬 | Releitura, prompt caching, context rot, 1M tokens |
| **T2 — Rotina Prática** ⚙️ | Plan mode, ciclos curtos, `/clear` `/rewind` `/compact` |
| **T3 — Handoff Inteligente** 🔀 | Resumo estruturado, CLAUDE.md enxuto, memória externa |
| **T4 — Técnicas Avançadas** 🧩 | Subagentes, divisão de sessões, Markdown vs PDF |
| **T5 — Exemplos Práticos** 🛠️ | Cenários reais passo a passo, prompts prontos |
| **T6 — Nível Avançado** 🚀 | Caching strategy, orquestração multi-modelo, `/context` |

## Como usar

Abra `index.html` no navegador ou sirva localmente:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.
